            Performance
            
            

          

          

            Advanced
            
            
            
            
            
            
            
            
            
            

              Large Gaussian PLY files are read in chunks and packed outside the WASM heap, so a multi-gigabyte
              file is never one ArrayBuffer. Spherical harmonics drop first, then splats are subsampled, if the
              device budget cannot hold the whole cloud. Sorting still runs in a WASM worker.
              Level of detail is off unless the address includes ?lod=force, and only for a cloud of at
              least 400,000 splats. Lower memory never builds that tree.
              Compressed formats (.spz, .sog, .splat, .ksplat,
              .rad) only follow the rendered harmonics, the pixel ratio, and whether the previous scene
              is cleared, because Spark decodes them itself.
              A paged .rad is the bounded-memory route, and the format that loads instantly next time;
              baking one is a Spark build-lod step, not a download from this page.
