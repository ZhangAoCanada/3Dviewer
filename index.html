Performance

Large Gaussian PLY files are read in chunks and packed outside the WASM heap, so a multi-gigabyte file is never one ArrayBuffer. Spherical harmonics drop first, then splats are subsampled, if the device budget cannot hold the whole cloud. Sorting still runs in a WASM worker. A paged .rad is the format that loads instantly next time; baking one is a Spark build-lod step, not a download from this page.
